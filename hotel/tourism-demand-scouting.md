```
根据国内居民出游抽样调查结果，2026年前三季度，国内居民出游人次53.07亿，比上年同期增加
3.09亿，同比增长6.2%。其中，城镇居民国内出游人次40.37亿，同比增长6.6%；农村居民国内
出游人次12.70亿，同比增长5.1%。

```

**城镇 / 农村永远同时给**（可比两档）。累计期之外，上半年稿还额外给**分季度**拆分：
```
分季度看，一季度国内居民出游人次19.01亿，同比增长6.0%；二季度国内居民出游人次15.62亿，同比增长4.8%。
```
—— 这是同一年内「累计 + 单季」并存，**必须分两个粒度建概念**（`ytd` vs `quarterly`），
与 A 股锦江简报「1-11 月 vs 单月」是同一类陷阱。

## 配套：统计公报里的旅游与住宿单点（年度）

`2026-06-02` 的《2025 年文化和旅游发展统计公报》（39,599 B，正文 HTML）一句话给出四个面：

```
2025年，入境游客15450万人次，同比增长17.1%。其中，外国游客入境3517万人次，同比增长30.6%；
中国香港、中国澳门和中国台湾居民入境11932万人次，同比增长13.7%。内地居民出境旅游14836万人次，同比增长20.8%。
2025年末，全国共有旅行社70354家，星级饭店7586家。通过统计直报系统报送和审核的星级旅游饭店
营业收入1448.0亿元，平均房价360.2元/间·夜，平均出租率46.8%。
```

这是 **5.2 供需板的「需求侧」与「供给侧」唯一的同年同源交汇点**：
出游需求（人次/花费）来自季度稿，住宿供给（星级饭店家数/营收/ADR/OCC）来自年度公报。

## 坑位

1. **不是表，是句子**：所有数字在中文 prose 里，抽取器必须做「中文数词 + 单位」解析
   （`53.07亿` / `4.95万亿元` / `1.86万亿`），且 `亿` 与 `万亿元` 单位不同（人次 vs 金额）。
2. **累计期用词不统一**：`2025年`（全年）、`2026年一季度`、`2026年上半年`、`2026年前三季度`
   —— 期次必须从标题解析，不能按发布日推算（发布日滞后 2–5 个月）。
3. **公报是年度、季度稿是累计**：两者不可互相补齐（公报的入境/出境/星级饭店数字季度稿里没有）。
4. **「比上年增加 X 亿」与「同比增长 Y%」并存**：两个都给，可互相校验
   （`53.07 - 3.09 = 49.98` = 2025 前三季度值，实测对得上）。
5. **正文页含大量 CSS**（`<style>` 内联），朴素 strip 标签会把样式当正文 —— 必须先剥 `<style>`。
6. 期次命名与星级饭店报告**共用同一栏目**，按标题前缀区分（`…国内居民出游数据情况` vs
   `…全国星级旅游饭店统计调查报告`）。
