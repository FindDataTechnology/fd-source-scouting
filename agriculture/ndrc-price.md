# ndrc-price 侦察报告

侦察时间：2026-11-08；范围：国家发改委（NDRC）官网公开侧 + 价格监测中心子站。
方法：`curl --noproxy '*'`（清空 http_proxy/https_proxy/all_proxy），共 8 个探测点，全部国内直连；未登录、未绕反爬。

## 结论

**NDRC 官网公开侧不提供可机器采集的「猪粮比价 / 生猪出场价格」周度数据通道 → 本波判定：不可得（结构化）。**

三条硬证据：

1. **发改数据栏目无畜牲口数据。** `https://www.ndrc.gov.cn/fgsj/`（发改数据）的五个分区为：数说经济、经济数据概览、经济运行与调节、产业发展、粮食流通。全站数据入口只落到这五项，**没有畜牧 / 生猪 / 价格监测分区**；该页 76 个链接中，含「生猪 / 猪粮 / 比价」的链接数为 **0**。
2. **唯一的周度价格数据是粮食收购价，且是图片。** 「粮食流通 → 市场监测」列出的是《全国主要粮食品种收购价格周报》（玉米在其口径内），单篇正文 **0 个 `<table>`**、数据在一张 PNG 里，且**来源标注为国家粮食和物资储备局**，不是 NDRC 价格监测体系自身产出。
3. **价格监测中心子站已改造为登录制内部系统。** `jgjc.ndrc.gov.cn` 解析成功（114.246.31.75），但 302 到 `/portal/pchtml/index.html`，标题《国家发展和改革委员会价格监测预警系统》，页面链接全部指向 `https://iam.ndrc.gov.cn/...entityID=jgjcyj` 单点登录与 `fgw.sso.ndrc.gov.cn/login.html`——**公开侧无数据页面**。

站内检索同样不可用：`www.ndrc.gov.cn/search/` 返回 404；`so.ndrc.gov.cn/s` 存在但返回「不存在的站点[]」，需要未知的站点 ID 参数（3 次尝试 siteid=1 / sitecode=bm04000001 / 无参，均失败）。因此「全站是否还有某篇新闻稿正文提到猪粮比价」这一层**未能穷尽**，本报告不作断言。

## 真实样例值

**未取得任何猪粮比价 / 生猪出场价格数值。** 本站探测到的所有响应中都不含这两个指标，故此处不填任何数字（不凭记忆补写，包括不写预警分级线数值——阈值须在实现期从官方预案原文核定）。

## 坑位

1. **TLS 兼容**：`jgjc.ndrc.gov.cn` 对 LibreSSL 默认握手直接断连（SSL_ERROR_SYSCALL），必须 `--tlsv1.2 --tls-max 1.2 -k` 才拿到 302。仅此一点即可让普通 curl/requests 默认配置全部失败并误判为「站点挂了」。
2. **http 301 → https**，且 https 又 302 到 `/portal/pchtml/index.html`；只跟一层重定向会落到 0 字节。
3. **登录制陷阱**：价格监测预警系统门户首页**不需要登录也能 200**，容易误判「可接入」；实际所有数据入口都是 `iam.ndrc.gov.cn` ticket。这不是反爬，是内部业务系统，不做绕过。
4. **数据来源标注误导**：粮食周报挂在 NDRC 域名下，但「来源：国家粮食和物资储备局」——按域名归属会被误算成 NDRC 自产数据。
5. **图片型正文**：`<table>` 为 0，正文 5KB 全是壳；按「找 table 解析」的思路会得到空结果而不是报错。
6. **站内检索不可用**：`so.ndrc.gov.cn` 需站点 ID，`/search/` 404。想用检索兜底验证必须先从真实搜索页拿到 siteid（本次未拿到）。
7. **历史公开域名失联**：`www.chinaprice.gov.cn` 无 DNS，别把「价格监测中心数据在 chinaprice」写进设计文档。

## 建议

1. **本波结论落地**：农业线阈值预警的判据**不能**依赖 NDRC 官网抓取。要么换源，要么改用「新闻稿正文关键词命中」做弱信号（只能得到方向性表述，得不到连续周序列，不适合做阈值判定）。
2. **优先级换源**：生猪出场价与猪粮比价的权威周度序列，改探农业农村部（畜牧兽医局 / 信息中心「生猪产品价格」周报）与各省发改委「价格监测」栏目转载（省级栏目历史上有全国猪粮比价表，形态多为 HTML 表格）。这两处本次未探，不在本报告结论内。
3. **若仍要 NDRC**：解锁条件 = (a) 从真实搜索页 JS/请求中取得 `so.ndrc.gov.cn` 的 siteid，全站检索「猪粮比价」确认是否存在新闻稿级发布页；(b) 确认价格监测中心是否有新的公开域名（chinaprice 已无解析）；(c) 若命中页面，再判断正文是数值叙述还是表格。三条同时成立才有接入价值。
4. **阈值零假设**：猪粮比价分级线（如预警区间边界）**一律不得凭记忆写入代码或 spec**，实现期必须取官方预案原文逐条核定并落引用。
5. **工程提示**：即便未来接入 NDRC 系站点，客户端需固定 TLS1.2 上限 + 容忍 301/302 链，且必须做「正文无 table」的显式失败分支，否则会静默返回空数据。
