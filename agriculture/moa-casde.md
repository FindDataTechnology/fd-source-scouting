## 数据通道

**列表页（主）**
- `https://www.agri.cn/sj/gxxs/` ，分页 `index_2.htm`、`index_3.htm` …（实测 1/2/10 页均为 200，10 条/页）
- 条目锚文本规律：`href="./YYYYMM/tYYYYMMDD_<id>.htm" title="<标题>"`，正则可直接抽：
  `href="([^"]*t\d{8}_\d+\.htm)"[^>]*title="([^"]+)"`
- 标题形如 `2026年10月中国农产品供需形势分析（CASDE-No.124）` —— **报告号 No. 单调递增，是最好的期次主键**。
- 栏目是混合流：除 CASDE 外还夹 `中国大蒜供需平衡表（大众版/详细版）`、`中国罗非鱼供需报告`、`中国南美白对虾供需报告`，需按标题过滤 `CASDE`。

**详情页（主）**
- 直接 `GET`，无需 UA/Cookie/Referer（实测裸 curl 200）。
- 正文：`来源：农业农村部市场预警专家委员会`，`时间：2026-10-09`。
- 数字形态：**5 张 HTML `<table>`**，每张 18–24 行；表内首行为期次表头，其后有 `千公顷（1000 hectares）`、`万吨（10000 tons）` 等单位行（单位在表中独立成行，解析时需向下继承）。
- 附件：`https://www.agri.cn/zxfile/reader?file=https://www.agri.cn/sj/gxxs/202610/P020261009761814578950.pdf`

**监测预警（辅，非平衡表）**
- `https://www.agri.cn/sj/jcyj/` 有 `2026年9月大宗农产品供需形势分析月报`、`鲜活农产品供需形势分析月报`、周度 `国内外农产品市场动态`、`畜产品和饲料集贸市场价格情况`。同样是 10 条/页、同样 `index_N.htm` 分页。若要价格周序列，走这里。

## 坑位

1. **moa.gov.cn ≠ 数据源**。moa.gov.cn 首页导航未见「供需形势」入口，真正栏目在 `agri.cn`（中国农业农村信息网，农业农村部主办）。别在 moa 站内检索上浪费预算。
2. **列表是混合流**。大蒜/罗非鱼/对虾专报与 CASDE 同列，且「大蒜供需平衡表」有两个版本（大众版/详细版）易误采。必须用标题里的 `CASDE-No.` 过滤。
3. **单位在表格里独立成行**（`千公顷（1000 hectares）`、`万吨（10000 tons）`、`元/吨`、`美分/磅`），一个 table 内有多次单位切换；直接 `pandas.read_html` 会把单位行当成数据行，需要向下继承 + 清洗。
4. **同一张表并列「上月预测」与「本月预测」**（`2026/27(9月预测)` vs `2026/27(10月预测)`），列名带中文括号，跨期列名不稳定（月份数字会变），不能硬编码列名，要按列位置 + 括号内月份解析。
5. **历史条目被重挂到 2023-11-30 目录**，URL 年月 ≠ 报告所属年月，必须从标题/正文 `时间：` 取期次。
6. **尾页不可信**：模板渲染 `index_19.htm` 实际 404，翻页要处理 404 终止而不是按页数计数。
7. 详情页 435 KB，含大量版式脚本/内联样式；正文纯文本仅约 6.6 K 字符。抓取时别存整页。
8. 图片（11 张）**不承载数字**，不需要 OCR；PDF 附件是平行副本，非必需（文本层未验证）。

## 建议

- **接入方式**：列表页 `index_N.htm` 增量扫（N=1 起）→ 标题匹配 `CASDE-No.(\d+)` → 详情页 → 取 5 张 table 转长表。主键 `(casde_no, commodity, item)`，同时保留 `forecast_month` 以容纳「9月预测/10月预测」双列。
- **回溯**：按 No. 从 124 递减翻页，直到某页无 CASDE 条目或 404；不必解析尾页。
- **校验**：用正文叙述里的产量口径（如「大豆产量2036万吨」）对 table 内 `产量` 行做一致性断言，能低成本抓出解析错位（单位行串行是最高风险）。
- **PDF 备用**：仅当某期 table 缺失时再考虑 `zxfile/reader` 附件，需先验证文本层（本次未测）。
- **优先级**：这是目前见到形态最好的一类源（结构化 HTML 平衡表 + 单调递增期次号 + 月度稳定），可直接进 L1/L2。
