# fertilizer-pesticide 侦察报告

日期 2026-11-08｜只读 HTTP 探测｜国内直连（--noproxy '*'）｜8 个探测点 + 2 次 DNS 预检｜全部 <5MB

## 结论（两行）

- **化肥：可接入（industry 档，非协会档）** — `www.fert.cn`（中肥网）公开「统计数据」栏目有月度**进出口量/金额/平均单价**文章，数值直接写在 HTML 正文，可机器解析；但**产量与出厂价在 vip 子域，需会员登录**，且运营方是商业门户而非协会。
- **农药：不可得（协会侧）** — 中国农药工业协会（CCPIA）官网无任何统计/价格/产量栏目，只有新闻与会员内容；官方 `chinapesticide.org.cn` 数据中心仅登记/许可查询，无产量或价格序列。

## 化肥通道

**站点与运营方**
- `www.fert.cn` = 中肥网 / 中国化肥网络平台。页脚仅「Copyright © 2002-2026 中肥网」，未标注协会或事业单位主办 → 商业行业门户，不是协会。
- `www.cnfia.cn` 解析成功但为**中国食品工业协会**，与中国氮肥工业协会无关；氮肥协会正确域名本轮未定位（预算内未再试）。
- 中国农资流通协会：本轮未探测，状态「未验证」。

**栏目结构**
- `/10005/`「化肥产量统计数据_进出口统计数据」：公开，列表页直接列出标题+日期+详情链接，分页可枚举。
- `/11002/`「价格行情」：公开栏目存在（首页导航可见），本页内容**未验证**。
- `vip.fert.cn/price/`（出厂价格）、`vip.fert.cn/yield/`（产量数据）、`vip.fert.cn/market/`（区域行情）、`vip.fert.cn/business/`（数据图表）：均指向会员子域，**需登录，按约束不进入**。
- 首页「产量数据」条目（如 2026年10月尿素实物产量）链接均为 `vip.fert.cn/view.asp?id=...` → **产量序列为会员内容**。

**形态**
- 公开部分：网页文章（HTML 正文），gb2312 编码，数值以中文句子陈述，非表格、非 PDF、非图片。
- 会员部分：网页文章，需登录（未验证内容格式）。

**真实样例（2026-10-13，来源标注「全国海关信息中心」）**
```
2026年8月 中国尿素出口量 52.46 万吨，金额 217,872,915 美元，平均单价 415.28 美元/吨
  环比 +30.0%（上月 40.34 万吨），同比 -34.1%（2025年同期 79.67 万吨）
2026年8月 中国尿素进口 45.35 吨，金额 211,830 美元，平均单价 4,670.90 美元/吨
  环比 +28.0%，同比 -41.6%
```
同页列表另有硫酸/磷矿石/硫磺/原油/无烟煤/二元复合肥/三元复合肥/硝酸钾/硫酸钾/氯化钾/磷酸一铵/磷酸二铵 等月度进出口条目，字段结构一致（量、金额、均价、环比、同比）。

**判定**：公开可得的是**月度进出口量/额/均价**（价格代理可用），**不是**国内产量、也不是零售/出厂价格指数。字段稳定、发布节奏月度、无需登录 → 可接入；但 authority 应记 `industry`（商业门户转载海关数据），标 `authority=association` 会失真。

## 农药通道

**站点**
- `www.ccpia.org.cn` = 中国农药工业协会，解析到 `aliyun.xiehuiyi.com`（阿里云建站），200 正常。
- 全站一级导航只有：关于我们 / 新闻动态 / 重点工作 / 会员单位 / 行业荣誉 / 下载中心 / 会员风采 / 责任关怀。**没有「统计」「数据」「价格」「指数」「行业运行」栏目**。
- 首页 HTML 中「统计/产量/价格/指数/运行/数据」关键词出现次数均为 0。
- 行业新闻列表（`/article/13_1353_0_0.html`）中相关命中仅 2 条，均为「经济运行开门红」类通知，无数据表。

**形态**：新闻稿 + 通知 + 会员名录 + 下载中心（PDF 未验证）。即便有年度报告，也是 PDF/会员区，不构成可机器取序列。

**官方替代（政府侧）**
- `www.chinapesticide.org.cn`（农业农村部农药检定所 / ICAMA）200 正常，有「数据中心」。
- `/zwb/dataCenter` 实测：农药登记、试验单位、生产许可查询、经营许可查询、核准标签查询、互联网经营备案、有效成分查作物、登记信息公布/公告/公示。**无产量、无价格、无指数**；登记数据是准入记录，不能当产量或价格的代理。

**判定**：协会侧**不可得**；官方侧只有登记类数据，同样不含产量/价格。障碍=协会不公开发布统计序列（可能仅会员/纸质年报），无技术性绕过手段。

## 建议

1. 化肥标 `authority=industry`（不是 association），数据源用 `fert.cn/10005/` 月度进出口序列；形态为 HTML 文章，需按 gb18030 解码 + 正则抽「量/金额/均价/环比/同比」五个字段。仅作成本链背景变量，**不用于阈值预警**。
2. 若确实需要「产量」而非进出口：改用国家统计局月度化肥产量（government 档），或付费订阅 `vip.fert.cn/yield/`；两者均超本轮权限，标注为待定。
3. 农药在该主题下**不设数据源**，只保留「协会无公开序列」这一事实记录；如果业务必须要农药价格，需另找商业原药价格指数（如中农立华原药价格指数，本轮**未验证**），并归入 commercial 档。
4. 氮肥工业协会、中国农资流通协会的正确域名与数据栏目均**未验证**（DNS/预算内未覆盖），若要把化肥从 industry 升到 association，下一步应只补这两个点。
5. 采集注意：`www.fert.cn` 文章页为 gb2312，列表页为 UTF-8，编码不一致；同域名 https/http 均可，`-L` 后无跨域跳转。
